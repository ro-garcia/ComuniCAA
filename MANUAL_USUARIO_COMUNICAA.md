# Manual de Usuario de ComuniCAA

## 1. Presentacion

ComuniCAA es una aplicacion de Comunicacion Aumentativa y Alternativa (CAA) que permite construir mensajes usando pictogramas, texto escrito y salida de voz. Esta orientada a usuarios que necesitan apoyo visual para expresar necesidades, emociones, acciones, lugares, personas u objetos.

La aplicacion permite seleccionar pictogramas, formar una frase, reproducirla con voz, buscar palabras, escribir frases manuales y personalizar el tablero mediante pictogramas o carpetas.

## 2. Objetivo del manual

Este manual explica como utilizar ComuniCAA desde el punto de vista del usuario final y del cuidador, docente, terapeuta o responsable que configura la aplicacion.

Al finalizar la lectura, el usuario podra:

- Navegar por las secciones principales.
- Construir mensajes con pictogramas.
- Reproducir mensajes en voz alta.
- Buscar pictogramas.
- Escribir frases manuales.
- Personalizar pictogramas y carpetas.
- Ajustar la apariencia y accesibilidad de la aplicacion.

## 3. Requisitos basicos

Para utilizar ComuniCAA se necesita:

- Un dispositivo Android, iOS o navegador web compatible.
- Tener instalada o ejecutada la aplicacion.
- Tener el volumen del dispositivo activo para escuchar la salida de voz.
- Permitir acceso a camara o galeria si se desean crear pictogramas personalizados.

## 4. Inicio de la aplicacion

Al abrir ComuniCAA se muestra la pantalla principal de comunicacion. Desde esta pantalla se puede construir un mensaje usando pictogramas.

La interfaz esta organizada en tres areas principales:

| Area | Funcion |
| --- | --- |
| Barra de mensaje | Muestra los pictogramas o textos seleccionados para formar la frase. |
| Tablero principal | Presenta pictogramas, categorias o carpetas disponibles. |
| Barra inferior | Permite cambiar entre Carpetas, Buscar, Teclado, Inicio, Editar y Ajustes. |

## 5. Barra inferior de navegacion

La barra inferior permite moverse entre las funciones principales de ComuniCAA.

| Boton | Funcion |
| --- | --- |
| Carpetas | Muestra la organizacion de pictogramas por categorias o carpetas. |
| Buscar | Permite localizar pictogramas escribiendo una palabra. |
| Teclado | Permite escribir una frase manual. |
| Inicio | Regresa al tablero principal de comunicacion. |
| Editar | Activa o desactiva el modo cuidador para personalizar elementos. |
| Ajustes | Abre las opciones de personalizacion visual y comunicativa. |

## 6. Construir un mensaje con pictogramas

Para crear un mensaje:

1. Presione el boton **Inicio**.
2. Busque en el tablero el pictograma que desea usar.
3. Toque el pictograma una vez.
4. El pictograma aparecera en la barra de mensaje.
5. Repita el proceso hasta formar la frase deseada.
6. Presione el boton de volumen en la barra de mensaje para escuchar la frase.

Ejemplo:

```text
Yo + quiero + agua
```

La aplicacion convertira la seleccion en una frase y la reproducira en voz alta.

## 7. Reproducir el mensaje

Cuando ya se han seleccionado pictogramas o se ha agregado texto manual:

1. Revise que la barra de mensaje contenga la frase deseada.
2. Presione el boton **Hablar mensaje**, identificado con el icono de volumen.
3. La aplicacion reproducira el mensaje.

ComuniCAA intenta usar primero audios pregrabados. Si un pictograma no tiene audio disponible, la aplicacion utiliza Text-to-Speech (TTS) para pronunciar el texto asociado.

## 8. Corregir o limpiar el mensaje

La barra de mensaje incluye acciones para corregir la frase.

| Accion | Funcion |
| --- | --- |
| Hablar | Reproduce el mensaje construido. |
| Borrar ultima palabra | Elimina el ultimo pictograma o texto agregado. |
| Limpiar mensaje | Borra todo el mensaje actual. |

Use **Borrar ultima palabra** cuando solo necesite corregir el ultimo elemento. Use **Limpiar mensaje** cuando desee empezar una frase nueva.

## 9. Uso de categorias y carpetas

ComuniCAA organiza los pictogramas en categorias para facilitar el acceso al vocabulario.

Las categorias iniciales son:

- Esenciales
- Personas
- Comida
- Emociones
- Lugares
- Actividades
- Objetos
- Favoritos

Para usar una categoria:

1. Presione **Carpetas** o seleccione una categoria visible en la pantalla principal.
2. Toque la categoria deseada.
3. Se mostraran los pictogramas relacionados.
4. Seleccione el pictograma que desea agregar al mensaje.

Las carpetas funcionan como grupos personalizados. Al tocar una carpeta, se muestran los pictogramas que contiene.

## 10. Buscar pictogramas

La opcion **Buscar** permite encontrar pictogramas rapidamente.

Para buscar:

1. Presione el boton **Buscar** en la barra inferior.
2. Escriba una palabra en el campo de busqueda.
3. Revise los resultados.
4. Toque el pictograma deseado para agregarlo al mensaje.

Si no se encuentran resultados, la aplicacion mostrara un mensaje indicando que no se encontraron pictogramas.

## 11. Usar el teclado

La seccion **Teclado** permite escribir frases manuales cuando el usuario necesita expresar algo que no esta representado por pictogramas.

Para escribir una frase:

1. Presione **Teclado**.
2. Escriba la frase en el campo de texto.
3. Presione **Agregar al mensaje** para colocarla en la barra de mensaje.
4. Presione **Hablar** o el boton de volumen de la barra de mensaje para reproducirla.

Esta funcion es util para frases nuevas, nombres propios o expresiones que aun no tienen pictograma.

## 12. Modo cuidador o modo edicion

El modo cuidador permite personalizar el tablero. Desde este modo se pueden crear pictogramas, crear carpetas, editar elementos y modificar ajustes.

Para activar el modo cuidador:

1. Presione el boton **Editar** en la barra inferior.
2. La aplicacion activara las opciones de personalizacion.
3. Aparecera un boton flotante para crear elementos.

Para salir del modo cuidador:

1. Presione nuevamente **Editar**.
2. La aplicacion regresara al modo de uso normal.

## 13. Crear un pictograma personalizado

Para crear un pictograma:

1. Active el modo cuidador con el boton **Editar**.
2. Presione el boton flotante **Crear**.
3. Escriba el nombre del pictograma.
4. Escriba el texto que pronunciara la aplicacion.
5. Seleccione una categoria o carpeta.
6. Agregue una imagen usando una de estas opciones:
   - Tomar fotografia.
   - Elegir desde galeria.
7. Si desea, marque el pictograma como favorito.
8. Presione **Guardar pictograma**.

Despues de guardar, el pictograma quedara disponible en el tablero, categoria o carpeta seleccionada.

## 14. Crear una carpeta

Las carpetas permiten agrupar pictogramas personalizados o relacionados.

Para crear una carpeta:

1. Active el modo cuidador.
2. Ingrese a la seccion **Carpetas**.
3. Presione el boton flotante **Crear carpeta**.
4. Escriba el nombre de la carpeta.
5. Seleccione o tome una imagen para identificarla.
6. Presione **Guardar carpeta**.

La carpeta aparecera en el tablero y podra abrirse como un grupo de pictogramas.

## 15. Editar pictogramas o carpetas

En modo cuidador, mantenga presionado un pictograma o carpeta para abrir opciones de administracion.

Segun el elemento seleccionado, podra:

- Editar datos del pictograma.
- Cambiar nombre.
- Cambiar imagen.
- Modificar texto hablado.
- Agregar o quitar del tablero.
- Convertir elementos en carpetas, si la opcion esta disponible.
- Eliminar pictogramas personalizados.

Nota: los pictogramas base de la aplicacion pueden estar protegidos para evitar eliminacion accidental.

## 16. Favoritos

La categoria **Favoritos** permite acceder rapidamente a pictogramas frecuentes.

Para usar favoritos:

1. Active el modo cuidador.
2. Edite o cree un pictograma.
3. Active la opcion **Favorito**.
4. Guarde los cambios.
5. Ingrese a la categoria **Favoritos** para verlo disponible.

## 17. Ajustes de personalizacion

La pantalla **Ajustes** permite adaptar la aplicacion a las necesidades del usuario.

### Ajustes de tablero

| Opcion | Funcion |
| --- | --- |
| Densidad del tablero | Cambia la cantidad y distribucion de pictogramas. |
| Barra de carpetas | Permite ubicar las carpetas arriba, abajo u ocultarlas. |
| Posicion del texto | Cambia la posicion del texto en pictogramas. |
| Colores por categoria | Activa colores diferenciados para categorias. |
| Barra inferior oscura | Cambia el contraste de la barra de navegacion. |
| Tamano de pictogramas | Aumenta o reduce el tamano visual de los pictogramas. |
| Alto de barra de carpetas | Ajusta el espacio ocupado por las carpetas. |
| Redondez de celdas | Modifica la forma visual de las tarjetas. |

### Ajustes de apariencia

| Opcion | Funcion |
| --- | --- |
| Tema oscuro | Cambia la aplicacion a modo oscuro. |
| Mostrar texto en pictogramas | Muestra u oculta las etiquetas de los pictogramas. |
| Alto contraste | Mejora la diferenciacion visual de elementos. |
| Tamano de texto | Aumenta o reduce el tamano de letra. |

### Ajustes de comunicacion

| Opcion | Funcion |
| --- | --- |
| Hablar al pulsar | Reproduce el pictograma inmediatamente al tocarlo. |
| Mostrar barra de mensaje | Muestra u oculta la barra superior del mensaje. |
| Mostrar pictogramas en mensaje | Controla si los pictogramas aparecen en la barra. |
| Alto de barra de comunicacion | Aumenta o reduce la altura de la barra de mensaje. |

## 18. Recomendaciones de uso

- Coloque en el tablero principal los pictogramas mas usados.
- Use favoritos para palabras frecuentes como "agua", "ayuda", "comer" o "bano".
- Cree carpetas por rutinas, por ejemplo: escuela, comida, emociones o actividades.
- Use imagenes claras y reconocibles para pictogramas personalizados.
- Active alto contraste si el usuario tiene dificultad visual.
- Ajuste la densidad del tablero segun la precision tactil del usuario.
- Use frases manuales para palabras que aun no tienen pictograma.

## 19. Solucion de problemas

| Problema | Posible causa | Solucion |
| --- | --- | --- |
| No se escucha la voz | Volumen bajo o audio bloqueado. | Suba el volumen y vuelva a presionar hablar. |
| Un pictograma no reproduce audio pregrabado | No existe archivo de audio para ese pictograma. | La app usara TTS si esta disponible. |
| No aparece un pictograma nuevo | No fue agregado al tablero o esta dentro de una carpeta. | Busquelo en su categoria/carpeta o agreguelo al tablero. |
| No se puede guardar pictograma | Falta nombre o imagen. | Complete los campos obligatorios. |
| La pantalla muestra muchos elementos | Densidad demasiado alta. | Cambie la densidad a amplio o compacto. |
| El texto se ve pequeno | Escala de texto baja. | Aumente el tamano de texto en Ajustes. |
| La imagen no carga | Imagen local no disponible o permiso denegado. | Seleccione nuevamente una imagen desde galeria o camara. |

## 20. Buenas practicas para cuidadores

- Revise periodicamente los pictogramas mas utilizados.
- Mantenga el tablero simple al inicio y aumente vocabulario gradualmente.
- Agrupe palabras por rutinas del usuario.
- Evite saturar la pantalla con demasiados pictogramas.
- Use palabras claras y frases cortas.
- Pruebe la salida de voz despues de crear o editar pictogramas.
- Ajuste el tablero segun edad, contexto y habilidades del usuario.

## 21. Glosario

| Termino | Definicion |
| --- | --- |
| CAA | Comunicacion Aumentativa y Alternativa. |
| Pictograma | Imagen o simbolo que representa una palabra, accion o idea. |
| Tablero | Pantalla donde se muestran pictogramas para construir mensajes. |
| Barra de mensaje | Area donde aparecen los pictogramas o textos seleccionados. |
| TTS | Text-to-Speech, tecnologia que convierte texto en voz. |
| Modo cuidador | Modo de edicion para personalizar pictogramas, carpetas y ajustes. |
| Categoria | Grupo de pictogramas relacionados por tema. |
| Carpeta | Contenedor personalizado para organizar pictogramas. |

## 22. Cierre

ComuniCAA esta disenada para facilitar la expresion de ideas mediante apoyos visuales y auditivos. Su uso continuo permite adaptar el tablero a las necesidades de cada persona, mejorar la rapidez de comunicacion y fortalecer la autonomia del usuario.
